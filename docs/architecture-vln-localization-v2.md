# VLN 与三维定位融合方案图

## 表达重点

VLN 是导航决策核心；三维激光定位提供地图位姿、连续性和健康状态；独立安全执行层把模型轨迹转换成可执行命令。载体为用户提供图片中的云深处山猫 S10 轮足机器人，四条腿的末端均为轮子。

## 定位报告中的工程事实

- 双激光扫描经过外参统一、时间同步、去畸变和降采样。
- BBS3D 完成全局几何搜索，GICP 完成精配准，并经多帧一致性与合理性判定建立地图位姿。
- NDT-OMP 连续地图匹配，IMU 辅助短时姿态约束。
- map、odom、base_link 和传感器外参采用可追溯的坐标关系，测量路点与地图须统一局部原点、单位和坐标轴。
- 健康监督器管理 TRACKING、DEGRADED、LOST、RELOCALIZING；丢失时零速保持，验证恢复后放行。
- 报告提供 479 秒、527.83 米连续定位记录；起终点 0.37 米间距不等于绝对定位精度。
- BEVPlace++、RING#、语义描述和时序多假设为研究增强；不画成已部署基础链。
- 三维可通行性、楼层拓扑、连接区模式和 MPPI 属于报告方案。多楼层/楼梯实机闭环及与 VLN 的统一执行接口仍需联调。

## 本图的融合设计

1. 任务编排保存 31 个必经点，按顺序逐站下发世界坐标 Goal 和语言指令。
2. 坐标适配器根据可信 6DoF 位姿计算机器人坐标系的局部 GoalPoint，并使用与训练一致的轴约定和尺度。
3. VLN 接收 20 帧历史 front、当前 left/front/right、odom、instruction 与局部 GoalPoint；输出局部轨迹和 STOP。
4. 红心作为可见的目标语义进入图像；没有红心时，仍依据 GoalPoint 与定位到达目标。不把新增独立红心检测器画成现有模块。
5. 模型轨迹通过控制接口、近场障碍约束和 cmd mux 驱动 S10。仿真已有 pure-pursuit；实机 MPPI/专用运动模式对接标为待联调。
6. 逐站完成条件设计为 STOP、定位距离阈值和连续稳定判定的联合条件。阈值由比赛规则和定位误差预算配置，不将当前仿真误差直接作为实机保证。
7. 执行状态和新观测回馈下一模型步；到点确认后下发下一站。安全监督可独立抑制速度或零速保持。

## 离线闭环

同源实景扫描生成点云定位图及 Gaussian 数字孪生。后者结合碰撞网格与 NavMesh 支撑轨迹采样、人工修正、GoalPoint LoRA 训练与仿真评测。图中明确完整 Gaussian/俯视地图用于建图、训练和观察，不作为整图输入 VLN。

## 证据与版本

图依据用户提供的《三维定位与多楼层自主导航算法框架评审报告》及本项目已有 GoalPoint 模型输入约定制作。实机定位验证与 VLN 仿真验证分别成立；本图中的融合系统为整体设计，不表示完整实机闭环已通过验收。
