# 系统架构

## 在线链路

```text
Gaussian / 碰撞网格 / NavMesh
              |
三视图观测 + SLAM 位姿 + 当前任务 Goal
              |
世界坐标 Goal -> 机器人局部 GoalPoint
              |
Goal Point VLN 模型
              |
waypoint 序列 + STOP 概率
              |
pure-pursuit / 运动控制 / 碰撞与安全层
              |
逐站结果检查 -> 下发下一 checkpoint
```

## 设计原则

- **逐站闭环**：比赛路线拆成 30 个相邻 checkpoint episode。机器人确认当前站点完成后，工程控制器才发送下一目标。
- **定位与视觉互补**：SLAM/odom 提供连续几何目标；红心视觉提示帮助模型在终点附近选择更合适的停车位置。
- **目标不随机器人漂移**：Goal 保存为世界坐标。每一步依据最新位姿重新计算局部 GoalPoint。
- **可通行与控制解耦**：NavMesh 表达可通行表面，碰撞网格约束真实障碍；规划结果不直接作为模型视觉输入。
- **证据分层**：数字孪生路线、模型仿真推理与真实机器人录像分别标注，避免把不同层次的结果混为一谈。

## 展示指标

正式逐段成功条件为模型输出 STOP 且终点误差不超过阈值。网站同时公开 0.25m、1m 和最大误差，并保留碰撞与失败案例，以便复核。
