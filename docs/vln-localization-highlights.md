# VLN 与定位融合导航：亮点与边界

## 核心思路

传统定位链路持续提供机器人在地图坐标系中的位姿，并将世界目标转换为局部 Goal Point；VLN 模型结合单视图或左／前／右三视图、多帧观测、语义指令和 Goal Point，输出局部导航决策与 STOP。两者不是替代关系，而是“几何定位保证可度量，视觉语义负责理解现场”的融合关系。

## 算法亮点

- **定位与视觉互补：**定位负责逐站目标、距离和到点判定；VLN 可利用道路、台阶、草地、石块等视觉上下文修正局部行进决策，对小幅、缓慢的定位漂移具有一定容忍度。
- **语义目标对齐：**“到达目标点并尽量停在红心上”等目标可作为指令与训练样本的一部分注入 VLN。模型在整体视觉语境中对齐目标语义，不要求额外串接一个只识别红点的专用检测器。
- **纯视觉部署路径：**模型本身可仅依赖单视图或三视图、多帧信息和语义输入完成导航；因此在定位退化或地图不可用时，具备纯视觉导航的理论可行性。当前逐站精准停车仍由定位提供坐标约束和结果校验。
- **训练仿真闭环：**高保真高斯场景、可通行几何和人工校正轨迹为复杂园区地形提供可控的数据采样、训练和验证环境。

## 主要不足

- **依赖训练覆盖：**模型效果受场景外观、光照、地形、路线和语义指令分布影响；遇到训练未覆盖的目标样式或环境变化，纯视觉语义对齐可能退化。
- **边缘算力开销：**多视图、多帧 VLN 推理需要 AGX 侧持续提供 GPU 算力，并受到端侧延迟、功耗和热设计约束；需与控制频率共同优化。
- **不能取代安全与定位：**较大的定位跳变、严重遮挡或视觉失效不能仅靠 VLN 兜底，仍需要定位健康监测、避障、安全仲裁与必要的重定位机制。
